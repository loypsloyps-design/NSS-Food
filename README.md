# NSS Food

SaaS de delivery para restaurantes. Fase 1: protótipo React/TypeScript com cardápio, carrinho, pedidos locais e painéis demonstrativos. Não usar dados pessoais reais. Não processa pagamentos nem envia WhatsApp. Não possui autenticação ou persistência multiusuário nesta fase.

## Executar

`npm install` e `npm run dev`. Build: `npm run build`.

## Próximas etapas

Supabase Auth, tabelas multi-tenant, RLS, criação segura de pedidos, Realtime, webhooks assinados do provedor de pagamento, WhatsApp Cloud API com consentimento e templates, assinaturas e testes. Chaves secretas exclusivamente no backend. Nunca confiar em preços ou confirmação de pagamento do navegador.
